## 📌 About

This site serves as an interactive hub and visual log of my web development progress. Instead of navigating separate repositories, every project completed along The Odin Project curriculum is presented here as an interactive card linking directly to its live preview and source code.

### Key Focus Areas:
* **Clean Code:** Semantic HTML5, accessible structure, and maintainable styling.
* **Modern Layouts:** Hands-on mastery of CSS Grid and Flexbox without relying on UI frameworks.
* **Progressive Growth:** Continuous updates as new curriculum projects and algorithms are completed.
